# Official Brand Color Palette

## 🎨 **Exact Brand Colors**

### **Primary Colors:**
1. **Dark Brown** `#521D07` - All text & headings (was #3E3632)
2. **Golden Emblem** `#A47A2D` - All buttons & accents (was #D4AF37 and #D6CFC4)  
3. **Cheetah Orange** `#FFA51F` - ONLY hover states & small icons (use sparingly!)
4. **Cream Background** `#FDF5E7` - Background (was #FAF8F5)

## 🔄 **Complete Find & Replace List:**

### **Text Colors:**
- `#3E3632` → `#521D07` (Dark Brown)
- `#6B5D52` → `#521D07` (Dark Brown)
- `#4A5568` → `#521D07` (Dark Brown)

### **Button/Badge Colors:**
- `#D6CFC4` → `#A47A2D` (Golden Emblem)
- `#D4AF37` → `#A47A2D` (Golden Emblem)
- `#C9A232` → `#A47A2D` (Golden Emblem) 
- `#B8B0A6` → `#A47A2D` (Golden Emblem - dark mode)

### **Hover/Accent (Orange - Use Sparingly):**
- Add `hover:text-[#FFA51F]` to links
- Small icons/dots use `#FFA51F`
- Status indicators use `#FFA51F`

### **Background:**
- `#FAF8F5` → `#FDF5E7` (Cream)
- `#F6F7F2` → `#FDF5E7` (Cream)

## ✅ **Application Rules:**

1. **Headings** → Dark Brown `#521D07`
2. **Body text** → Dark Brown `#521D07`  
3. **Buttons** → Golden Emblem `#A47A2D`
4. **Pills/Badges** → Golden Emblem `#A47A2D`
5. **Hover states** → Cheetah Orange `#FFA51F`
6. **Small icons** → Cheetah Orange `#FFA51F` or Golden Emblem `#A47A2D`
7. **Backgrounds** → Cream `#FDF5E7`
8. **Cards** → White `#FFFFFF` on Cream background

## 🚫 **Do NOT Use:**
- No more beige/sand colors
- No more old gold tones
- Orange ONLY for hovers and tiny elements
- Keep it minimal and premium
