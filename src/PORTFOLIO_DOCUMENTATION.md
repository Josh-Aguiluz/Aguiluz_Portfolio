## 🎨 VISUAL DESIGN SYSTEM

### **Color Palette (Boyish Pastel)**
- **Background:** Cream (#FDFBF7) - Warm, soft base
- **Primary:** Electric Blue (#3B82F6) - Trust, professionalism
- **Secondary:** Mint Green (#6EE7B7) - Fresh, modern
- **Accent:** Cement Grey (#E5E7EB) - Subtle contrast
- **Text:** Deep Navy (#1E3A8A) - Readable, sophisticated

### **Typography**
- **Headings:** Fraunces (900 weight, 96px-144px for H1)
- **Body:** Nunito (700-900 weight, 24px minimum)
- **Style:** All uppercase headings, bold body text
- **Print-ready:** Large sizes ensure readability on paper

### **Visual Elements**
- **Shapes:** Heavy rounded corners (40px+ border radius)
- **Shadows:** Layered drop shadows for depth
- **Decorations:** Stars ★, code brackets {}, @ and # symbols
- **Animations:** Wiggle, bounce, float effects on hover
- **Layout:** Center-aligned for symmetry and impact

## 🚀 IMPLEMENTATION NOTES

### **Technologies Used:**
- **Framework:** React with TypeScript
- **Styling:** Tailwind CSS v4
- **Fonts:** Google Fonts (Fraunces + Nunito)
- **Animations:** CSS keyframes + Tailwind utilities
- **State Management:** React useState for theme toggle
- **Persistence:** localStorage for theme preference
- **Icons:** Emoji for universal compatibility + playful touch

### **Performance Optimizations:**
- Smooth scroll behavior
- Hardware-accelerated animations (transform, opacity)
- Lazy loading considerations for images
- Optimized font loading
- Minimal JavaScript for fast load times

### **Accessibility:**
- High contrast ratios (WCAG AA compliant)
- Large, readable text (24px minimum body)
- Keyboard navigation support
- Semantic HTML structure
- ARIA labels where needed
- Focus indicators on interactive elements
